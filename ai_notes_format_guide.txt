2. HEADING HIERARCHY & FLOW
--------------------------------------------------------------------------------
- <h1> : Main Title (Only ONE per page, e.g. HISTORICAL BACKGROUND & MAKING OF CONSTITUTION)
- <h2> : Primary Topics with unique IDs (Numbered, e.g., <h2 id="topic-1">1. Company Rule (1773 – 1858)</h2>)
- <h3> : Subtopics (Prefix subtopic title with branching arrow indicator '↳ ')
  Example: <h3>↳ Rights Exclusive to Indian Citizens</h3>

--------------------------------------------------------------------------------
3. THEMED CONTEXTUAL HIGHLIGHTS & COLOR TOKENS
--------------------------------------------------------------------------------
Never apply yellow highlight to standard headers or generic bold text. Standard bold text must use clean ink (<strong>). Only highlight core learning terms, dates, acts, and numbers:
- <strong class="hl-yellow"> : International bodies, committees, panels, milestones (e.g., Lord Ripon, Sarkaria Commission).
- <strong class="hl-pink"> : Penal restrictions, mandatory voting limits, major exceptions (e.g., 2/3rd majority, Article 356).
- <strong class="hl-green"> : Mandatory criteria, constitutional articles, rights (e.g., Article 21, 5 years, Oath of Allegiance).
- <strong class="hl-blue"> : Registries, databases, structural concepts (e.g., Dual Polity, Sial & Sima, 182 days).

6. MCQ JSON SCHEMA & QUIZZES CLASSIFICATION
--------------------------------------------------------------------------------
Every MCQ file must adhere to the standard JSON structure and be categorized under one of the 3 Group Types in `mcqs/quizzes.json`.

### A. Individual MCQ File Format (`*.json`)
```json
[
  {
    "question": "Which of the following channels separates the Andaman group of islands from the Nicobar group of islands?",
    "options": [
      {
        "text": "The Nine Degree Channel",
        "isCorrect": false,
        "rationale": "The Nine Degree Channel separates Minicoy Island from the main Lakshadweep archipelago."
      },
      {
        "text": "The Ten Degree Channel",
        "isCorrect": true,
        "rationale": "The Ten Degree Channel lies on the 10°N parallel, separating Little Andaman from Car Nicobar."
      },
      {
        "text": "The Duncan Passage",
        "isCorrect": false,
        "rationale": "The Duncan Passage separates South Andaman from Little Andaman."
      },
      {
        "text": "The Palk Strait",
        "isCorrect": false,
        "rationale": "The Palk Strait separates India (Tamil Nadu) from Sri Lanka."
      }
    ],
    "hint": "This channel is named after the parallel of latitude running between the two island groups."
  }
]
```

### B. Group Type Classification Rules in `mcqs/quizzes.json`
Every topic module registered under a subject MUST have an explicit `"groupType"` property:
1. `"groupType": "subject_test"` : Normal Subject Practice Tests (topic-wise chapter practice modules in `mcqs/polity/`, `mcqs/geography/`, etc.).
2. `"groupType": "selection_test"` : Selection Tests (100-question comprehensive Adda247 exam modules in `mcqs/selection_test/`).
3. `"groupType": "full_mock"` : Full-Length GS Mock Exams (100-question GS papers in `mcqs/fulltest/`).

### C. Option Shuffling Rule
- Never keep the correct answer (`"isCorrect": true`) hardcoded at position 0 (index 0) for all questions.
- Always randomly shuffle the options array across positions 0, 1, 2, and 3 so the correct option distribution is evenly spread.

7. A4 PRINT & PDF ALIGNMENT RULES
--------------------------------------------------------------------------------
To ensure notes render perfectly on A4 paper prints and PDF exports without content overflow or awkward white spaces:
- Modular Content Blocks: Keep 'qa-block' cards, 'sticky-note' boxes, and 'table' grids modular (avoid page-long unbroken containers). Stylesheet uses `break-inside: avoid;` to keep blocks together.
- H2 Page Breaks: Always use `<h2>` for major topics. The CSS automatically forces a clean page break before every `<h2>` heading (except the first heading).
- Heading Sibling Rules: Always place the intro text or table immediately following an `<h2>` heading to enforce `break-before: avoid;` and prevent orphaned headings at the bottom of pages.

--------------------------------------------------------------------------------
8. OCR DIGITIZATION & FACT VERIFICATION RULES
--------------------------------------------------------------------------------
When digitizing raw text, PDF scans, or handwritten notes:
- Zero Content Deletion: Never omit or delete any existing facts, dates, cases, articles, or committee names.
- Fact Verification & Correction:
  - If a sentence is incomplete or ambiguous, complete it accurately using standard NCERT / Laxmikanth UPSC reference knowledge.
  - Fix spelling mistakes, archaic terms, or invalid article numbers.
  - Expand abbreviations on first mention (e.g., "CAA" -> "Constitutional Amendment Act (CAA)").
- Formatting Integrity: Apply clean HTML syntax, high-contrast highlights, tables, and Mermaid flowcharts for complex processes.
